Adding cards

Copy data/packs/_template.json to a new name (e.g. calvin.json) and fill it in:

{
  "name": "My Pack",
  "black": [
    "____ is the reason I got kicked out of the library.",
    { "text": "____ + ____ = a terrible weekend.", "pick": 2 }
  ],
  "white": [
    "A suspiciously warm chair",
    "Forty raccoons in a trench coat"
  ]
}
  • Use four underscores ____ for a blank. pick is inferred from the number of blanks, so you only need it for cards with no blanks that want 2+ answers.
  • Black cards without any blank (questions like "What ended my last relationship?") get the answer appended.
  • Run python scripts/validate_packs.py to check your JSON before starting the server.
